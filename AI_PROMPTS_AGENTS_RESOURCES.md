Covers explicit AI/ML tools, prompt engineering, agent frameworks, coding assistants, MCP integrations, research workflows, memory and RAG, model infrastructure, evaluation, and media applications. Human intelligence agents and HTTP user-agent utilities are excluded. Model announcements and benchmark claims are historical source descriptions, not current recommendations. Long descriptions may be shortened.

**Sources** link to the original timeline files; each label gives the issue number and source line. A resource may appear in more than one topic collection when relevant.
