## 🛠 OSINT Tools, Services & Investigations

**Edgextract.** Turn markdown into a knowledge graph with an ontology you write and a cutoff you own. Closed yes/no decisions, not free-form JSON:

**Hexestra** is an AI-native penetration testing IDE where human operators and the AI Agent work on the same operational surface-sharing the browser, terminal, traffic, shells, asset graph, task plan, evidence, and controls:

## 🤖 Universal Search & AI

**Learn Harness Engineering.** A project-based course on building the environment, state management, verification, and control mechanisms that make AI coding agents work reliably:

🔗 https://github.com/walkinglabs/learn-harness-engineering

**Best of Agent Harness and Harness Techniques.** Ranked list of 167 AI agent harnesses, plus templates, playbooks, MCP, and learning resources. Rescored weekly:

🔗 https://github.com/RyanAlberts/best-of-Agent-Harnesses

**Better Codex.** A task board and Agent system inside Codex Desktop. Local-first, open source, macOS and Windows:

🔗 https://github.com/Ericwong5021/better-codex

**ClawBrowser.** Agent-native browser with fingerprint control and proxy support:

🔗 https://github.com/clawbrowser/clawbrowser

**Kander.** A kanban board for coordinating multiple AI coding agents, with isolated git worktrees and independent reviewer agents:

🔗 https://github.com/dualface/kander

**Heretic.** Fully automatic censorship removal for language models:

🔗 https://github.com/p-e-w/heretic

**Mensarium** is a self-hosted agent harness. You install **Core** on a server or a laptop, pair your other computers, and give the agent work from a browser or Telegram. The model never touches a machine directly: it only proposes an action, Core checks it against a policy, asks you when the action changes something, and sends the machine a signed request. Everything, from chats to keys and the activity log, stays on your hardware:

🔗 https://github.com/NGdust/mensarium

**NodeDB.** The memory & storage engine for AI agents. Multi-model, edge-to-cloud, PostgreSQL-compatible:

🔗 https://github.com/NodeDB-Lab/nodedb

**Maister.** Self-hosted execution and governance for reproducible AI-powered software delivery over private code:

🔗 https://github.com/maister-dev/maister

**Joxo.** One shared project for your team's Claude Code, Codex, Cursor and OpenCode agents: a task board, decisions and handoffs. Everyone keeps their own plan:

🔗 https://github.com/JoxoAI/joxo

**Knotra.** AI workflows you can verify, inspect and resume. Turn a task into a repeatable process: models do the reasoning, code checks the result, and people approve the steps that need judgment. Knotra keeps the execution history and files across restarts:

🔗 https://github.com/michael-bill/knotra

**HoneyComb.** AI coding agents forget. They forget across sessions, and they forget across tools. A decision you reached in Claude Code at midnight is invisible to Cursor the next morning. Honeycomb fixes that. Learn something once; recall it everywhere:

🔗 https://github.com/legioncodeinc/honeycomb

**CortexDB.** AI memory and a knowledge graph in one SQLite file. Pure Go: vectors, RAG, agent memory, RDF/SPARQL, Cypher, 80+ MCP tools. Works without an embedding model:

🔗 https://github.com/liliang-cn/cortexdb

**UFO** is an open source runtime for AI agents. Team members give agents work in chat. Agents can read files and run commands to complete that work:

🔗 https://github.com/ufo-ai/ufo-core

**Maestro Orchestrate.** Multi-agent orchestration platform for Gemini CLI, Claude Code, Codex, and Qwen Code - 39 specialists, parallel subagents, persistent sessions, and built-in code review, debugging, security, SEO, accessibility, and compliance tools:

🔗 https://github.com/josstei/maestro-orchestrate

**OKF Agent Memory.** Git-native persistent memory for AI coding agents. Implements Google OKF v0.2 with sub-300µs in-memory BM25 search, embedded MCP server, and progressive disclosure. Slashes token bloat by 80% with zero external databases or dependencies. Built in pure Go:

🔗 https://github.com/okf-memory/okf-agent-memory

**KGLite.** Embedded Cypher knowledge graph for Python and Rust. Bundled MCP server, describe() schema, and code-graph parser for LLM agents:

🔗 https://github.com/kkollsga/kglite

**Clisbot.** Agentic Coding CLI & chat bot:

🔗 https://github.com/longbkit/clisbot

**OpenCreator.** Formerly KrillinAI, VideoTranslation and Dubbing Tool. Open-source AI workspace for creators, powered by Codex. Video downloading, video translation, create videos, images, voice, avatars, and edits with Agents in one place. Suitable for your Social Media like YouTube, TikTok, Instagram, etc.:

🔗 https://github.com/krillinai/OpenCreator
