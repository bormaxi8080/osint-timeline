## 🤖 Universal Search & AI

**A harness2** is the system around a model that enables it to act as an agent: prompts, tools, memory, skills, orchestration, and more. **Harnessing** is the process of optimizing that system. Harness² is a plug-and-play framework for **recursive agent harnessing** in an open world, where agents encounter tasks unseen during harness design:

🔗 https://github.com/google-research/harness2

**AIOS.** The local-first control plane for long-horizon coding agents: cross-session project memory (ContextDB), adaptive workflow routing, multi-agent teams, resumable overnight runs, and verifiable evidence - on top of Codex CLI, Claude Code, Gemini CLI, OpenCode, Hermes, Grok, WorkBuddy, Pi, ZCode, and Qoder:

🔗 https://github.com/rexleimo/aios

**Eleven.** Agent-first reverse engineering for macOS, Windows and Linux: any ACP agent reads, renames and patches binaries, Android apps and GPU kernels next to you:

🔗 https://github.com/Zfinix/eleven

**KiwiFS.** Markdown filesystem for agents and teams. Searchable. Structured. Versioned. One binary, zero config:

🔗 https://github.com/kiwifs/kiwifs

**Dexto.** Agent harness and tookit for building AI agents and agentic applications. CLI and SDKs included:

🔗 https://github.com/truffle-ai/dexto

**Ankole.** The open source Agent Harness with a Company Brain. Self-hosted AI Agents for Slack, Teams, Lark, DingTalk, WeCom, and more. An open source alternative to Claude Tag:

🔗 https://github.com/AgentBull/ankole

**Trigora.** High-performance, lightweight durable execution for long-running AI agents and programs:

🔗 https://github.com/trigora-dev/trigora

**OLMOCR.** Toolkit for linearizing PDFs for LLM datasets/training:

🔗 https://github.com/allenai/olmocr

**Tellurion.** Ghostty for macOS, rebuilt to watch AI coding agents work live. Claude Code, Codex and more in a vertical sidebar, a code editor that types in their edits as they happen, a live code map, a backend view (Cloudflare, Supabase, Vercel), Visual Fix, agent races and change review:

🔗 https://github.com/steventsvik/Tellurion

**SolonGate Agent Security** is SolonGate's open source, local first security gateway for AI coding agents. It checks tool calls against your policies before they run, with secret detection, rate limits and a local audit trail:

🔗 https://github.com/solongate/agent-security

**Strata.** Qwen3.8-Flash-Next on any consumer hardware: one-click install for Windows / Linux. Strata inference engine, OpenAI/Anthropic API on localhost, optional image input:

🔗 https://github.com/Niko1221/Strata
