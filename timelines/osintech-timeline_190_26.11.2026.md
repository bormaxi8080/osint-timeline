**Global Hack Map - tracking cyber incidents, exploited vulnerabilities and data breaches**  
  
**Global Hack Map** is an open-source platform that brings publicly reported breaches, ransomware claims, actively exploited vulnerabilities, malicious packages and connectivity disruptions together on an interactive globe.  
  
Incidents include links to their original sources and are labelled as confirmed, reported, claimed, precautionary or disputed. The platform also provides a feed of recently published critical CVEs and vulnerabilities added to the CISA Known Exploited Vulnerabilities catalog.  
  
Users can select products and companies to explore possible exposure. For developers, the project provides CVE remediation runbooks that can be opened in Claude Code, Codex or Cursor. It also includes a read-only MCP server and llms.txt for AI agents.  
  
The project is built with TypeScript, Next.js and Mapbox. It can be self-hosted under the MIT license. Public security feeds work without a Valyu API key, while news extraction, AI-generated answers, research reports and explainers require one.  
  
The map relies on public feeds, media reporting and attacker claims. Data may be delayed or incomplete, and a missing result should not be treated as evidence that an organization or product is unaffected.

🔗 https://github.com/yorkeccak/globalhackmap

## 🐧 Linux & DevOps

**JumpServer** is an Open-source Privileged Access Management (PAM) platform with AI-powered capabilities, providing DevOps and IT teams a unified workspace to securely access SSH, RDP, Kubernetes, databases, websites, RemoteApp, VirtualApp, and more:

🔗 https://github.com/jumpserver/jumpserver

**Telescope.** Web-based log viewer UI. Explore logs data stored in several sources: ClickHouse, Kubernetes or Docker:

🔗 https://github.com/iamtelescope/telescope

**VPS Monitor.** A lightweight, Go-based VPS monitoring solution with real-time web dashboard supporting multiple agents. Monitor unlimited servers from a single dashboard overview analytics:

🔗 https://github.com/hhftechnology/vps-monitor

**Backhaul.** Lightning-fast reverse tunneling solution for NAT traversal, optimized for handling massive concurrent connections with tcp, tcpmux, udp, udp over tcp, ws, wsmux, wss and wssmux support:

🔗 https://github.com/Musixal/Backhaul

**MirrorSync.** A Docker container that **mirrors folders one-way, 1:1** (like FreeFileSync "Mirror"): the destination becomes an exact copy of the source, including deletions. The sync engine is [rclone](https://rclone.org/), so **SMB, WebDAV (Nextcloud …), SFTP/SSH, FTP/FTPS, S3, local folders** and many more work, in any combination (e.g. SMB → WebDAV). Two-way sync is available too:

🔗 https://github.com/DerMilderJoghurt/mirrorsync

**rs-top** is a lightweight, agentless, and read-only remote system monitor. It provides a real-time TUI dashboard for monitoring multiple remote hosts simultaneously via SSH. Heavily influenced by classic tools like `top`, `htop`, and `btop`, it aims to provide a similar experience for remote servers:

🔗 https://github.com/ruiiiijiiiiang/rs-top
